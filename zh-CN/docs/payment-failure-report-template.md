# 支付失败报告模板

对比案例、开GitHub Issue或者公开求助时，可以直接复制这份模板。

发之前先把敏感信息打码。

```text
产品：
付款渠道：web / Apple / Google Play / API / workspace-team / 其他
账号国家/地区：
发卡国家/地区：
付款类型：首次付款 / 续费 / 未付invoice / 其他
大致金额和币种：
完整报错：
本次尝试的UTC时间：
有没有出现3D Secure/其他身份验证：有 / 没有 / 不确定
银行/发卡方有没有看到authorization授权请求：有 / 没有 / 不确定
如果有，银行显示的状态/原因是什么：
这张付款方式以前在同一个商户成功过吗：是 / 否
如果成功过，只成功过首笔，还是至少成功续费过一次：
和上一次成功付款相比，什么发生了变化：
已经尝试过什么：
```

## 不要贴这些东西

- 完整卡号
- CVV
- 完整账单地址
- 护照/身份证件图片
- API Key
- 密码
- session cookie
- 恢复码
- 含敏感账号信息、但没有打码的截图

## 为什么模板里特别问这两个问题

通常最值钱的是两件事：

1. 实际走的是哪条billing route；
2. 银行/发卡方到底有没有看到authorization授权请求。

很多表面上都叫“card declined”的问题，只要把这两件事搞清楚，后面的排障路线就完全不一样了。
